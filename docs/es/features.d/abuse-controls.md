# Resistente al abuso por defecto

- Las descargas de paquetes de seeds están limitadas por IP de cliente, así un solo equipo no puede agotar el servidor.
- Las visitas web a la portada se limitan por separado de los clientes reales de reseed.
- Un archivo opcional de lista negra de IP bloquea direcciones abusivas antes de que alcancen las seeds.
