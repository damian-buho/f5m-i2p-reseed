# Самостворювані ключі підпису

- Перший запуск автоматично створює ключ підпису SU3 — без запитів і ручних кроків.
- Ключі зберігаються в томі й ніколи не перестворюються поверх наявної ідентичності.
- Паралельний контейнер зі спільним томом не може пошкодити недописаний ключ.
- Сертифікат підпису готовий до подання під час реєстрації сервера в команді I2P.
